تأیید

راهنما

لینک‌ها

لینک نود را مستقیم در کلاینت وارد کنید یا از لینک اشتراک استفاده کنید. قالب‌های Clash و sing-box همان نودها را با تنظیمات مخصوص خود می‌دهند.

منبع IP

حالت تصادفی IPها را از محدوده‌ی Worker می‌سازد. فهرست دستی از ADD.txt خوانده می‌شود و مولد، IPها را از یک API بیرونی می‌گیرد.

پروکسی

PROXYIP برای عبور از CDN است. SOCKS5 و پروتکل‌های دیگر ترافیک را از یک پروکسی بیرونی می‌فرستند. پیش از ذخیره با ابزار آزمون، اتصال را بررسی کنید.

اعتبارنامه‌ها

توکن تلگرام و کلیدهای کلادفلر در KV ذخیره و در پاسخ API پوشانده می‌شوند. برای تغییر آن‌ها باید مقدار کامل را دوباره وارد کنید.

دامنه‌های سفارشی (HOSTS)

هر خط یک دامنه؛ بدون کاما.

تنظیم دامنه

دامنه‌ی فعلی پنل:

این دامنه در فهرست دامنه‌های نود نیست؛ اشتراک‌ها از دامنه‌ی فعلی استفاده نمی‌کنند.

دامنه‌های فعلی نود:

برای افزودن، دکمه‌ی ویرایش را بزنید و این دامنه را وارد کنید.

خاموش‌کردن رمزنگاری TLS

در حال خاموش‌کردن لایه‌ی TLS در Shadowsocks هستید. برای جلوگیری از قطع اتصال، محیط استقرار را بررسی کنید.

پیش از خاموش‌کردن TLS این سه مورد را بررسی کنید:

  1. پروژه باید روی Workers باشد (نه Pages).
  2. در کلادفلر گزینه‌ی «همیشه HTTPS» را خاموش کنید یا از دامنه‌ی *.workers.dev استفاده کنید.
  3. پورت IP/دامنه‌ی ترجیحی باید HTTP باشد؛ مثلاً 80، 8080، 8880، 2052، 2082، 2086، 2095.

پس از خاموش‌کردن TLS، داده‌ها روی HTTP منتقل می‌شوند اما خود محتوا با Shadowsocks AEAD رمزنگاری می‌شود.

هشدار نادیده‌گرفتن گواهی

Xray-core v26.1.31 و نسخه‌های بعدی پشتیبانی از «نادیده‌گرفتن خطای گواهی» را کنار می‌گذارند.

اگر کلاینت شما از این گزینه استفاده می‌کند، ممکن است اتصال قطع شود. فقط برای گواهی نامعتبر از آن استفاده کنید.

Xray-core v26.1.31

هشدار ALPN

انتخاب دستی ALPN ممکن است با CDN سازگار نباشد؛ در صورت ناسازگاری اتصال برقرار نمی‌شود.

مقدار انتخابی:

ECH و اثر انگشت

ECH فقط با اثر انگشت chrome یا firefox کار می‌کند. یکی را انتخاب کنید یا ECH را خاموش کنید.

اثر انگشت فعلی:

هشدار gRPC

شما XHTTP یا gRPC را انتخاب کردید. پیش از استفاده این دو مورد را بررسی کنید:

  1. پروژه باید روی Workers باشد (نه Pages).
  2. در پنل کلادفلر گزینه‌ی gRPC را برای دامنه فعال کنید، وگرنه نود ممکن است وصل نشود.
    مسیرNetwork > gRPC > On
