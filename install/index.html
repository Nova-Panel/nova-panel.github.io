تنظیمات، رمز مدیریت و داده‌های پنل در Workers KV ذخیره می‌شوند. برای ادامه باید یک Namespace با نام متغیر KV به Worker وصل باشد.

    2رمز مدیریت و اطلاعات اولیه
    اختیاری

    یک رمز برای ورود به پنل انتخاب کنید. این رمز همراه با اطلاعات اولیه در KV ذخیره می‌شود و بعداً از داخل پنل هم قابل تغییر است.

    حداقل ۶ کاراکتر. رمز را در جای امن نگه دارید؛ برای ورود به پنل لازم است.
    تنظیمات اولیه (اختیاری)
    اگر خالی بماند، ورکر از کلید پیش‌فرض استفاده می‌کند. برای امنیت بیشتر یک مقدار تصادفی وارد کنید.
    شناسه‌ی نود. اگر خالی بماند از رمز و KEY ساخته می‌شود.
    اختیاری. اگر دامنه‌ی اختصاصی دارید اینجا وارد کنید؛ در غیر این صورت دامنه‌ی Worker استفاده می‌شود.
    اختیاری. آدرس پروکسی معکوس برای اتصال به مقاصد مسدود.
    اختیاری. پیش‌فرض nginx است.
    اختیاری. مسیر WebSocket؛ پیش‌فرض / است.
    عملکرد و رفتار (اختیاری)
    لاگ دیباگ ثبت جزئیات بیشتر در لاگ Worker برای عیب‌یابی.
    غیرفعال کردن لاگ KV نوشتن گزارش بازدیدها در KV را متوقف می‌کند (مصرف KV کمتر).
    سازنده‌ی اشتراک بهینه (BestCF) درخواست ویژه‌ی BestCF را برای تولید اشتراک بهینه فعال می‌کند.
    پیش‌بارگذاری مسابقه‌ی اتصال اتصال‌ها را از قبل آغاز می‌کند تا تأخیر کمتر شود.
